# Femi Art — Touch of Love

An independent premium handmade and crochet boutique concept for Femi Art. The site is bilingual, responsive, and features an interactive 3D gallery.

## Deployment

This repository contains an `index.html` ready for GitHub Pages and a custom crochet-inspired WhatsApp floating button.

To publish: Settings → Pages → Deploy from a branch → main → /(root).

## Contact configuration

Set the official WhatsApp number (international digits, no + sign) in `whatsapp-widget.js` under `phone`. Until configured, the button opens WhatsApp's message-sharing flow rather than a direct brand chat. Product prices are not finalized; inquiries do not place paid orders.

Original client photos are for the proposed Femi Art storefront; confirm permission before public production use.
